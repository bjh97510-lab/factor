# 곱셈공식 & 인수분해 학습 웹앱

중학교 3학년과 고등학교 1학년 학생이 곱셈공식을 외우고 인수분해를 연습하는 웹앱입니다.

## 파일 구성
| 파일 | 역할 |
|---|---|
| `index.html` | 화면 구성 (Tailwind CDN, KaTeX 로드) |
| `curriculum.js` | 학년별 학습 내용: 플래시카드, 빈칸 문제 생성기, 인수분해 유형 |
| `app.js` | 학년 선택, 채점, 통계와 내역, 기록 초기화 |

## 실행
`index.html`을 더블클릭해 브라우저로 엽니다. Tailwind와 KaTeX를 CDN에서 불러오므로 인터넷 연결이 필요합니다.

## 화면 흐름
1. **첫 화면**: 중3과 고1 중 하나를 고릅니다.
2. **학습 화면**: 플래시카드, 빈칸 채우기, 인수분해, 학습 내역 탭이 있습니다. 🏠 버튼을 누르면 학년 선택 화면으로 돌아가고, 기록은 그대로 남습니다.
3. **기록 초기화**: 🔄 버튼을 누르거나 새로고침하면 모든 기록과 브라우저 저장소를 지우고 첫 화면으로 돌아갑니다.

## 학년별 내용
| | 중3 (다항식의 곱셈과 인수분해) | 고1 (공통수학1 · 다항식) |
|---|---|---|
| 플래시카드 | 곱셈공식 ①~④, 곱셈공식의 변형, 수의 계산, 인수분해 공식 (18장) | (a+b+c)², 세제곱 공식, 세제곱의 합·차, (x+a)(x+b)(x+c), a³+b³+c³−3abc, a⁴+a²b²+b⁴, 변형 공식, 치환, 인수정리 (22장) |
| 빈칸 채우기 | (ax±b)², 합차, (x+a)(x+b), (ax+b)(cx+d), 수의 계산, 변형 공식으로 식의 값 구하기 | (ax±b)³, 세제곱의 합·차, (x+a)(x+b)(x+c), (x²+ax+a²)(x²−ax+a²), 변형 공식으로 식의 값 구하기 |
| 인수분해 | 완전제곱식, 합차, x²+(a+b)x+ab, acx²+(ad+bc)x+bd | 완전세제곱식, 세제곱의 합·차, 인수정리(삼차식), 복이차식(치환), A²−B² 꼴 |

- 모든 문제는 무작위로 끝없이 만들어집니다. 인수분해는 난이도를 3단계 중에서 고를 수 있습니다.
- 인수분해 답 입력칸은 문제 유형에 맞는 틀로 나옵니다. 예: (x+□)(x²+□x+□)
- 채점은 입력한 식을 전개해 주어진 식과 같은지 비교하는 방식입니다. 그래서 인수의 순서를 바꿔 써도 정답입니다.
- 문제마다 첫 시도의 결과만 기록합니다.
